# Задания: Surface и изображения в Pygame

## Подготовка

Для выполнения заданий создай в папке проекта папку `images`.

Положи в неё одну PNG-картинку, например:

```text
images/star.png
```

Для загрузки изображения используй:

```python
star = pg.image.load("images/star.png")
```

Помни, что загруженная картинка — это тоже `Surface`.

Сайт с картинками: https://www.pngwing.com/ru

Константы для кнопок клавиатуры: https://docs.google.com/spreadsheets/d/1zq2GIpAd6wT97Dq_lw_JLK3rTE-s1FWfT7RaNomu7Sc/edit?usp=sharing

## Задание 1. Космический фон

Создай отдельную поверхность размером `400 × 300`.

Закрась её тёмно-синим цветом и нарисуй на ней:

- 10 маленьких белых кругов — звёзды;
- один большой жёлтый круг — планету;
- одну фиолетовую линию — орбиту.

Выведи эту поверхность в центре экрана.

## Задание 2. Движущаяся карточка

Создай поверхность `150 × 150`, закрась её и нарисуй на ней треугольник.

Выведи её на экран.

Сделай так, чтобы при нажатии стрелок карточка перемещалась по экрану. Она не должна выходить за границы окна.

## Задание 3. Загрузка картинки

Создай в папке проекта папку `images` и положи туда PNG-картинку, например `star.png`.

Загрузи её:

```python
star = pg.image.load("images/star.png")
```

Выведи картинку:

- в левом верхнем углу;
- в правом верхнем углу;
- в центре экрана.

Используй `get_size()`, чтобы правильно рассчитать координаты.

## Задание 4. Отражение картинки

Загрузи картинку и выведи её в обычном виде. Затем с помощью `pg.transform.scale()` создай её уменьшенную копию размером `100 × 100`.

Также создай:

- зеркальное отражение слева направо;
- зеркальное отражение сверху вниз.

И повёрнутые версии на:

- 90 градусов;
- 180 градусов;
- 270 градусов.

Используй:

```python
pg.transform.flip()
pg.transform.rotate()
```

Выведи все версии на экран.

## Задание 5. Кнопка с картинкой

Создай поверхность `200 × 80`, закрась её и нарисуй на ней рамку. Отобрази на ней картинку.

Выведи её в центре экрана.

Сделай так, чтобы при нажатии клавиши `SPACE` на кнопке появлялась картинка. А при нажатии на стрелки картинка должна передвигаться по экрану.

## Задание 6. Картинка с рамкой

Загрузи картинку и создай для неё рамку.

Сделай так, чтобы:

- при нажатии `K_UP` рамка становилась толще;
- при нажатии `K_DOWN` рамка становилась тоньше;
- толщина рамки не могла быть меньше 1px;
- толщина рамки не могла быть больше 20px.

Рамку можно нарисовать на отдельной поверхности и вывести её поверх картинки.

## Задание 7. Простой редактор

Создай поверхность `500 × 400` для рисования.

Сделай так, чтобы при нажатии клавиш:

- `K_1` — выбирался красный цвет;
- `K_2` — выбирался зелёный цвет;
- `K_3` — выбирался синий цвет;
- `K_SPACE` — на поверхности появлялся круг текущего цвета.

Выведи эту поверхность на экран.
