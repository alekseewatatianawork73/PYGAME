# Задания: Surface и изображения в Pygame

## Подготовка

Для выполнения заданий создай в папке проекта папку `images`.

Положи в неё одну PNG-картинку, например:

```text
images/star.png
```

Для загрузки изображения используй:

```python
star = pg.image.load("images/star.png")
```

Помни, что загруженная картинка — это тоже `Surface`.

## Задание 3. Движущаяся карточка

Создай поверхность `150 × 150`, закрась её и нарисуй на ней простой узор.

Выведи её на экран.

Сделай так, чтобы при нажатии стрелок карточка перемещалась по экрану. Она не должна выходить за границы окна.

### Подсказка

Храни координаты карточки в переменных `x` и `y`, а в `blit()` передавай `(x, y)`.

```python
screen.blit(card, (x, y))
```
