# Задания: Surface и изображения в Pygame

## Подготовка

Для выполнения заданий создай в папке проекта папку `images`.

Положи в неё одну PNG-картинку, например:

```text
images/star.png
```

Для загрузки изображения используй:

```python
star = pg.image.load("images/star.png")
```

Помни, что загруженная картинка — это тоже `Surface`.

## Задание 4. Движущаяся карточка

## Задание 12. Кнопка с картинкой

Создай поверхность `200 × 80`, закрась её и нарисуй на ней рамку.

Выведи её в центре экрана.

Сделай так, чтобы при нажатии клавиши `SPACE` картинка на кнопке поворачивалась на 90 градусов.

### Подсказка

Храни угол поворота в переменной `angle` и увеличивай его на 90 при нажатии пробела.

```python
angle += 90
rotated_image = pg.transform.rotate(image, angle)
```
